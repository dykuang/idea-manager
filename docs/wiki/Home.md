# IdeaMiner Wiki

IdeaMiner is a local-first workspace for capturing research ideas, developing them into traceable lineages, and finding useful connections across projects. Your SQLite library stays on your machine; agent services, SSH sync, and Codex integration are optional.

## The research loop

```text
Capture an idea → develop a lineage → run a micro-experiment
        ↑                                  ↓
   Dream / connect ← Serendipity ← Weekly Review and Gap Radar
```

The tools keep original captures, working notes, experiment results, and typed relations distinct so that new conclusions remain traceable to their sources.

## Quick facts

- The local SQLite database is the canonical library. No account or model key is needed for core use.
- Original idea captures are preserved separately from editable notes.
- Online agent calls are optional. Review exactly which context you include before sending it.
- GitHub releases and installation details are on the [releases page](https://github.com/dykuang/idea-manager/releases).
